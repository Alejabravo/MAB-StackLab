## Sobre el portafolio

MAB StackLab fue diseñado para presentar mi perfil profesional de una manera clara, organizada e interactiva.

Cuenta con una identidad visual basada en tonos vino, beige y dorado, una estructura adaptable a diferentes dispositivos y diferentes secciones que permiten conocer mi trayectoria.

**Características principales:**
- Diseño moderno y responsive.
- Navegación entre las diferentes secciones.
- Animaciones y efectos interactivos.
- Tarjetas de proyectos con información detallada.
- Filtros para explorar los proyectos.
- Enlaces a repositorios de GitHub.
- Secciones de experiencia, formación, habilidades y contacto.

## Proyectos destacados

### Huellitas

Plataforma web enfocada en el mundo de las mascotas, con funcionalidades orientadas a la visualización de productos, registro de usuarios y diferentes servicios para el cuidado animal.

**Tecnologías:** HTML, CSS, JavaScript y Bootstrap.

###  MichiApp

Aplicación móvil enfocada en los gatos, que integra diferentes funcionalidades relacionadas con su cuidado y entretenimiento.

Incluye perfiles, recetas, opciones de personalización y herramientas interactivas.

**Tecnologías:** React Native y Expo.

[Ver repositorio](https://github.com/Alejabravo/MichiApp)

### Calculadora de IMC

Aplicación web que permite calcular el índice de masa corporal a partir del peso y la estatura ingresados por el usuario.

Incluye validación de datos, clasificación de resultados e indicadores visuales.

**Tecnologías:** HTML, CSS y JavaScript.

### Registro de Usuarios

Aplicación web que permite ingresar información mediante un formulario y visualizar los registros de manera dinámica.

Este proyecto me permitió fortalecer mis conocimientos sobre componentes, eventos, estados y formularios en React.

**Tecnologías:** React, JavaScript, CSS y Vite.

[Ver repositorio](https://github.com/Alejabravo/registro-usuarios-react)

###  Rick and Morty App

Aplicación móvil inspirada en Rick and Morty, desarrollada para implementar diferentes sistemas de navegación entre pantallas.

Incluye navegación mediante Stack, Tabs y Drawer, permitiendo explorar diferentes secciones de la aplicación.

**Tecnologías:** React Native, Expo y React Navigation.

[Ver repositorio](https://github.com/Alejabravo/rick-and-morty-app)
